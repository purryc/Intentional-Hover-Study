# Hover Intent Study V2.3 / HOVER_INTENT_V2_3

旧记录和未结束会话保持原协议。旧配置缺少 revision 时按 V2.1 解码，revision.contentTargets 缺失时按 V2.2 解码；新会话默认 V2.3。手机区域仍为 (976,194,390,830)，任务提示和本任务内进度固定在正上方。姿势与任务任选，默认 A → B → C。

## 采集量与推进
|任务|默认计划量|完成/失败策略|
|---|---:|---|
|A1/A2|各18次|有效点击/拖动后推进，失败重试原题|
|A3/A4|各6次|有效滚动并抬笔后推进，失败重试原题|
|A5/A6/A7|各1段120秒|完整自然阅读后推进，中断重新开始本段|
|B1/B2/B3/B4|各12次|每次尝试均保留，成功或失败后推进|
|C1/C2|各12次|两条件各6次；成功后推进，失败重试原题|
|C3|36次|三场景×两条件各6次；成功后推进，失败重试原题|

默认 156 次短任务＋3段阅读。B 配平重复默认2套，每套6次，独立于全任务重复轮数，研究者可修改。B4 两/三个目标各6次。每套 B1/B2 三尺寸×双向配平。C 条件计划顺序连续不超过3次；失败重试不重抽条件，不把重复尝试计入该顺序限制。

A/C 失败等待默认1.2秒，提示“未完成，已保留本次记录；即将重试本题”，使用新 trialID，保留 attempt 与 redoOf，条件、几何、计划序号及剩余数不变。“重做当前次”结束当前尝试并重新开始，不跳过有效配额。后台及崩溃恢复均保留尝试并重做当前题；已经成功且等待推进时恢复应推进，避免重复已有效题。

有效数量按成功的唯一计划序号计，失败、跳过和中断按全部尝试计。B 成功率分别报告首次计划尝试和所有实际尝试；A/C 必须同时报告失败次数与每题尝试数，不能以最终配额完成率替代首次成功率。

## 小范围 C 目标
- A/B 抽象几何不变；C1 默认直径24/36/48pt，距离220pt，三尺寸×上下×两条件配平。
- C2 蓝色标记默认36×36pt，条带和80×80pt终点窗口共用实际几何。起点在手机中心，标记在纵向120pt外；起点稳定300ms后出现。滚动条件从标记开始接触，HOVER条件只在小标记内500ms提交，目标不再与强制起点重合。
- C3 默认48×48pt，指向许可素材 cover-1 中的蝴蝶。新闻在正文前展示346×194.625pt配图；图文使用首卡180×184pt图片；视频画面内固定300×168.75pt配图，背景视频保持实际播放。目标中心是原640×360素材中的(260,80)，使用与绘制相同的aspect-fill变换映射。位置固定，不跟踪视频中的运动物体。自然/主动条件共享同一图片及焦点；主动仅描边蝴蝶周围范围，不指向收藏星标。新闻与图文随滚动更新，离屏/打开详情时不可命中。视频目标是固定内容配图，不能将其结果解释为动态视频物体跟踪。
- C3 自然条件仅在同一指定小对象内静默记录500ms候选，便于同对象条件检验；A5–A7 继续完整内容对象的自然候选记录。两种候选范围由 protocolVersion/taskID/requested/selectionObjects 明确区分，旧协议候选率不可直接与新小区域候选率比较。

## 保留的行为
B1 连续500ms唤菜单，菜单保持并点击指定项，取消可重试；B2/B3 500ms零触屏选择，B4 原始XY闭合提交。圈选半径20pt、离开40pt、路径120pt、至少12点、奇偶围合面积2000pt²；缺口>100ms、结束/越界取消圈线，不跨缺口连接。目标中心在圈内或边界算选中，算法闭合边单独记录。普通短题超时20秒。
自然阅读无理解题；真实文章、双列图文及6条许可视频保持可操作。手指不操作页面，污染段单独保存；纯Hover触屏失败。停留在离开/切换/触屏/结束/暂停/缺口时重置。CSV每日追加、250ms写出、强制刷新、快照导出和尾行恢复继续沿用。

## 采集界面
顶部任务操作为“开始实验”“重做当前次”“导出 CSV”“结束实验”。参与者、姿势、任务勾选及参数放折叠配置区，参数直接生效，开始时统一校验。后台自动暂停后，点击开始实验恢复；保存失败提示点击重做当前次补写缓存后重做，若仍失败则继续暂停。结束实验将当前试次记为中断，写入会话结束事件并清除恢复检查点，历史 CSV 不删除。导出仍为快照。旧协议不在现代界面展示入口，原恢复及开发路径保留。

启动检查完成或恢复未结束试次后，左侧首页继续展开显示全部 A1–C3 任务及所选状态；采集期间配置不可修改，清单仍可浏览。当前任务、操作指令、次数/段数与暂停/保存恢复提示始终位于手机区域正上方的固定提示栏，不能以恢复试次摘要替换任务清单，也不在手机交互区叠加暂停指令。手机内只呈现任务目标和阅读内容。
