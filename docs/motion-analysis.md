# 手机仿真运动分析

只使用过滤后的手机区域 Pencil 数据。原 CSV 不变。所有派生指标独立于 3D 高度显示比例，不用于自动判断意图。

## 指标与计算

设相邻样本为 `(x₁,y₁,t₁)`、`(x₂,y₂,t₂)`，时间以秒计算：

- `vx=(x₂−x₁)/(t₂−t₁)`，`vy=(y₂−y₁)/(t₂−t₁)`；速度为 `sqrt(vx²+vy²)`，单位 pt/s，时间标在两点中点。
- 相邻速度向量再按其中点时间差求导得到 `ax/ay`，单位 pt/s²；`accelerationMagnitude=sqrt(ax²+ay²)`。
- 页面“切向加速度”曲线为相邻速度**幅值**的变化率；正值速度增大，负值速度减小。它与二维加速度幅值不同，速度相近但改变方向时仍可能有二维加速度。
- 距离为实测 XY 到目标**中心**的欧氏距离，单位 pt；并非目标边缘距离。
- Z 保留悬停 API 原值。接触时不填造 Z，也不与 XY 合成为物理空间速度或加速度。

同一连续段、同一输入来源分别计算。范围外点、被排除样本和来源切换造成的断线不跨越；非正时间差不求导。加速度需要三个相邻支持点；短段没有加速度是正常情况。

## 页面操作

3D 下方“运动规律”默认展示当前试次的速度、距离和 Z；点击曲线可跳转 3D 回放时间。加速度作为辅助分析收起。

“按落笔对齐”以每次首个有效 Pencil TOUCH_DOWN 为 0 ms，查看 −600 至 +100 ms。成功、失败、距离和目标尺寸可筛选；没有接触的试次不进入对齐。淡线代表各试次，亮线代表当前试次（需符合筛选）。3D 汇总时自动显示对齐图，其筛选与 3D 汇总范围独立。

默认展示原始计算曲线。可切换 80 ms 中值趋势：对每个已有指标时间点，取**同一段**前后 40 ms 内数值的中值。窗口边缘使用实际已有值，没有插值、补点或跨段平滑；原指标和导出保持不变。这是离线显示，使用未来 40 ms 信息，不适用于实时预测效果评估。

坐标差分放大抖动，尤其加速度。曲线反映 API 实际交付的位置变化，不是加速度计测量，不直接证明人的意图。条件混合的汇总仅供浏览，研究比较应先控制距离、尺寸和方向。

## `phone_kinematics.csv` 数据字典

派生指标为长表，每行对应一个指标；不替代原 SAMPLE/EVENT 数据。

| 字段 | 含义 |
|---|---|
| trialID / plannedIndex | 原试次 ID / 原计划编号 |
| distanceConditionPt / targetDiameterPt / success | 原距离、目标尺寸和结果 |
| segmentID / inputSource | 过滤后的连续段编号 / 原 Pencil 输入来源 |
| metric | speed、acceleration（切向速度变化率）、distance、z |
| timeFromTrialMs | 相对试次开始的时间；导数放在其支持区间时间中点 |
| value / unit | 指标值及单位 |
| supportSequences | 原 SAMPLE 序号，分号分隔；位置指标 1 点、速度 2 点、加速度 3 点 |
| vx / vy | 速度分量，仅 speed 行填入，pt/s |
| ax / ay / accelerationMagnitude | 二维加速度分量及幅值，仅 acceleration 行填入，pt/s² |

JSON 保存逐次连续曲线及首次接触时间。手机轨迹原样本与派生指标均可追溯原 CSV 的 SHA-256。
