# 两日 Hover 运动图谱：分析口径

## 输入与边界

输入为 2026-09-15 的 V2.1 CSV 与 2026-09-16 的 V2.3 CSV。原始 CSV 只读，结果单独写入 `analysis/trajectory_2026-09-16/two_day_motion_atlas/`。仅用手机局部区域 `0≤x≤390, 0≤y≤830` 的 Pencil 悬停点；手指、污染时段、悬停结束点、试次结束后的点均排除。同一连续段相邻样本间隔须为 `1–100 ms`，不跨缺口、接触或试次边界插值。两日任务布局、内容、重试规则与姿势并非严格配平，跨日曲线只作探索性描述。

## 事件与曲线

时间零点分别是 B1 的 `MENU_OPEN`、B2/B3/C1–C3 Hover 的 `HOVER_SELECT`、A5–A7 自然阅读的 `CANDIDATE`、A1/C1 Tap 的 `TOUCH_DOWN`。9/15 C3 自然条件虽有候选，但 9/16 C3 自然条件无候选，故两日主曲线均只用 A5–A7 阅读候选。主动/自然候选的 500 ms 是规则触发窗口；Tap 零点是接触，三种锚点不能解释成同一个心理阶段。每个事件最多取前 1 秒，只用一条连续悬停段；前 500 ms 覆盖至少 450 ms、至少 12 个样本才入主比较。重复候选保留事件曲线，同时报告独立试次数，不把多个事件当成多个参与者。

以 50 ms 箱计算每个事件的 XY 速度、速度变化率和 Z。速度由相邻点距离除以实际间隔，变化率由相邻速度差除以实际时间差；只在同一连续段求导。每个事件先生成箱内中位，再跨事件汇总中位与四分位范围，并列出每箱实际事件数。Z 保留 Apple Pencil API 原值；另用同事件早期可观测箱作为参考画相对变化，不换算毫米，不预设“数值下降”就是物理下沉。接近到停留的变化应与完整曲线和实际覆盖一起判断。

B3 额外按实际第 1/2/3 次 `HOVER_SELECT` 分组；比较接近段 `[-800,-500] ms` 与确认前 `[-300,0] ms` 的速度和 Z。配对要求前段至少 150 ms、末段至少 200 ms 实测覆盖，且为同一连续段；未采到连续接近段时不得填零或补点。逐事件保留试次 ID 与选择顺序，以免把一个试次的三次选择当成独立操作者。

## 3D 热区

Three.js 显示手机局部 X/Y（pt）与原始 Z（API 值）。每个有效连续样本间隔将实际 `dt` 加到前一个点所在体素；网格及 Z 范围固定，使不同日期/任务使用相同空间边界。热度表示该筛选组内观测悬停时间占比，悬停时长分母和体素数量同时显示。它是空间暴露图，受到目标布局与页面内容影响，不是意图概率；视觉高度比例仅为观察方便，不代表真实三维毫米距离。

## 推断范围

任务指令只提供“主动／自然”的代理标签，不是逐帧心理意图真值。两天若为同一参与者重复采集，不能当成独立样本。自然阅读的候选由相同 500 ms 规则产生，适合估算潜在误触机会；需要后续配平场景、对象和顺序，并在独立参与者上验证可迁移特征。
# 阅读 Home、Le 2019 对照与 800 ms 菜单补充口径

本补充只分析既有数据，不修改实验规则或原始 CSV。Home Position 是手机正面仿真区里 Pencil 笔尖的**空间位置候选**，和同一对象连续停留的时长是两个独立问题。Home 使用 A5–A7 完成阅读段的所有合格悬停观测边，按实际时间给 XY 网格加权，不读取 `DWELL_END`、`CANDIDATE`、速度或 Z 来决定是否进入 Home 样本。触摸、手指、污染、试次外与追踪缺口均排除，超过 100 ms 的边不连接。按日、姿势和场景分别估计，不先跨会话合并。

Home 的参考中心为整段中 50 pt 邻域累计观测时长最高的 20 pt 网格中心；前缀检查点为 2、5、10、20、30、45、60、90、120 秒。须有至少 1 秒有效悬停且峰值邻域占已观测悬停的至少 20%，才称为可估计；前缀中心距整段参考不超过 30 pt、且之后至少一个有新增观测的检查点继续满足此条件，才称回顾性稳定。中心和热区均使用手机局部 XY；圆圈半径为 50 pt。另以 60 秒前后两半的中心距离核查复现，≤50 pt 记同一空间区域。报告前缀墙上时间和至此实际收到的悬停秒数，避免把追踪缺口误认成等待定位。整段分布作为回顾性参考，故“最早稳定”不是可部署在线算法的前瞻性正确率。若没有合格数据，明确标“未定位”。

Le et al. 2019 官方数据记录右手单手握机时拇指与支撑手指的光学动捕位置，主要讨论背部非意图输入；本实验记录绑指 Apple Pencil 在仿真手机正面的悬停和触碰。两者部位、坐标基准、Z 单位和任务目标不同。可比较“自然阅读也有空间密集区和长时间离屏片段”“操作接近目标时运动状态发生变化”等形态级现象；不直接叠加 mm 与 pt、不能把 Le 的自然支撑移动标签当作本实验主动 Hover 的分类负样本。Le 结果须引用官方论文与数据仓库，局部 MOTION ATLAS 派生结果仅作复核说明。

菜单阈值回算以完整的同对象 `DWELL_END` 段为单位，长段只算一次。分别统计 A5–A7 内容对象和 C3 指定小对象，自然条件下 500 与 800 ms 的潜在触发次数、每记录分钟率，校核 500 ms 与原 `CANDIDATE`。不把此计数称为真实误触次数。B1 任务在连续 500 ms 达标时改变界面并弹出菜单，因此 800 ms 的主动操作时间被右删失；现有日志无法估计 800 ms 菜单成功率、召回率、准确率或延迟代价。阅读目标与 B1 抽象目标也不同，回算只作阈值风险提示。

交互版阈值以 100–1000 ms、25 ms 步长计算，每段完整同对象停留在一个阈值最多计一次。先保留已有采集事件对 500 ms 的核对：若日志已触发 `CANDIDATE` 而结束记录因时间取整略短于 500 ms，只在该段回算时提升到 500 ms，不外推到更高阈值。固定 500 ms 为比较基准，滑杆改变时按同一天／场景／对象口径更新候选数、每记录分钟数、相对变化和明细。小于 500 ms 可出现候选增加，不能写作“准确率下降”；大于 500 ms 的候选减少也不等于真实准确率提升。主动 B1 的 500 ms 菜单会改变后续行为，因此没有对应阈值的主动正确率或可证明的净收益。`threshold-800.json` 保留原 500/800 快照口径，`threshold-sweep.json` 保存派生计数曲线与输入 SHA，不放逐点样本。

可视化优先呈现上述三个问题各自的结论、分母与限制；六类行为跨两天四指标的原曲线保留为展开证据，避免在首屏混合不同单位或不同零点。3D 图里的 Home 圈仅标 XY 位置参考，不暗示 Z 是毫米高度。

## Touch / 阅读 Home / 主动 Hover 序列图（V2.4 报告布局）

新增 `sequence-comparison.png/json` 使用两份经原 CSV SHA-256 校验的回放缓存，不改动数据。A1 成功点击以实际 `TOUCH_DOWN` 对齐，A5–A7 只用前后半段 Home 位置复现的阅读试次，以 Pencil 从圈外首次进入 50 pt Home 圈对齐。主动 Hover 列分别绘制 B2 成功单选的全部 `HOVER_SELECT` 和 B3 后面还有下一个 `HOVER_SELECT` 的非末次选中；两条线各自统计，避免把单选与多选混成一条平均轨迹。每列 0 点的含义明确不同：阅读 Home 只是空间进入，**没有确认动作**。B2 与 Touch 通常很快结束，不能跨旧试次拼出“下一目标”；B3 可以观察同试次内的目标间迁移。B2/B3 目标布局不同，线形差异不能单独解释为任务意图效应。

从同一输入源且连续的实测 Pencil 段计算 XY 速度，相邻点需间隔 1–100 ms；接触与悬停分别求导，不在落笔、抬笔或缺口之间连线。距离取该事件当前目标或 Home 圈中心的手机局部 XY 距离。每个事件先按 50 ms 箱取中位，之后按事件取中位与四分位；三列距离共用一个纵轴上限、速度共用另一个纵轴上限。图内公开事件/试次数，JSON 公开每箱实际贡献数。阅读 Home 多次进入、B3 同一试次两次选择不代表多个独立参与者；不能从三类曲线直接算意图分类准确率。

第三排主图画 Z 原值变化速度 `|ΔZ|/Δt = |Z₂−Z₁|/(t₂−t₁)`，与 XY 速度一样从零开始，但使用独立的 API 原值/s 纵轴。只取同一连续 Pencil 悬停段内两个 Z 原值都有效、相隔 1–100 ms 的观测；**逐对取绝对值之后**，每个事件先按 50 ms 箱取中位，再汇总事件中位、四分位及有效数，三列共用非负 Z 速度刻度。派生 JSON 同时保留带符号的 `dZ/dt`：负值仅指 `zOffset` API 原值降低，正值指原值增加；不可先聚合带符号值再取绝对值来充当速度。两者都不是物理毫米每秒。Touch 接触时 Z 缺失以及任何追踪中断均留白，不以零填补。XY 距离、XY 速度与 Z 变化速度在不同纵轴上并列；确认点仍是各自真实事件，不将运动形态视作意图真值。

9 月 15/16 日没有任何前摄视线样本。报告的视觉热区部分只链接 [V2.4 采集方案](protocol-gaze-v2-4.md)并标记待采，绝不生成合成视线热区。新数据的眼手对照须先通过独立校准误差和时间对齐质量验收。

## 普通触屏动作补充

三列主图中的 Touch 只代表 A1 抽象点击，不能概括其他触屏行为。另列 A1 点击、A2 拖动、A3 竖滚、A4 横滚及 A5–A7 阅读中的触屏接触。A1–A4 仅取成功试次最后一次完整 `TOUCH_DOWN`→`TOUCH_UP`；阅读段取所有完整配对接触，保留原阅读任务，不按轨迹长度擅自改称点击或滚动。触屏动作使用绑指 Pencil，只有一位操作者，两日版本与姿势并未配平。

每次接触前 1 秒按 `TOUCH_DOWN` 对齐，悬停 XY 速度与 Z 原值变化速度分别由同一连续段、相隔 1–100 ms 的相邻样本计算；无有效点的时间箱留空。接触段只用 `PENCIL_TOUCH` 同源连续样本计算 XY 路径长度与速度，同时公开实际 `TOUCH_DOWN`→`TOUCH_UP` 时长。接触速度形态按每次接触的 0–100% 进度对齐，进度不是实时时间；不能据此比较动作快慢，速度纵轴仍以 pt/s 表示。接触时没有悬停 Z，不填零或跨抬笔连接。事件先按时间箱取中位，再跨事件给中位与四分位、每箱覆盖；重复阅读接触不算独立参与者。该区用于区分“接近触屏”和“保持接触操作”的运动过程，不将运动形态当意图真值。
