# 两轮轨迹比较方法

分析输入：`data/HoverIntent_2026-09-15 2.csv`。读取会话起止、真实输入来源、试次及配置，选取两轮完整 V2 会话；排除旧协议和短试操作。用户确认两轮均为右手，第一轮拇指、第二轮托握＋食指；原日志姿势标签另行保留。

轨迹仅保留手机局部 XY 边界内 Pencil，排除手指及污染时间段、悬停结束位置。输入来源切换、开始／结束、非递增时间、超过 100 ms 和被排除点均断线。指标限定 TRIAL_START 至 TRIAL_END；间隔中仍标为前一试次的点单独计为 outsideTrial，原 CSV 保留。失败及未完成尝试保留；手指触发失败的短任务不进入汇总轨迹。原 CSV 逐字节不变，派生记录保存 SHA256。

每条连续边用实际单调时间差计算 XY 速度；相邻速度向量求二维加速度幅值，时间放在支持区间中点，保留原始序号。全部合法边导出，主要分布以持续时间为权重，并排除短于 1 ms 的导数支持边，数量单独报告。该门槛处理回调极短间隔对导数的放大，不筛选空间轨迹。Z 单独报告原始值，不换算毫米。

报告按任务和条件比较每试次成功率、目标出现至完成时间、接触／悬停连续路径和运动分布。抽象指向额外检查目标出现后的路径、轴外偏移及回撤；不跨断线拼出路径效率。几何比较按任务、条件、场景、距离、直径和方向配对；B3/B4 布局按指定集合另行说明，阅读内容行为不强行配对。

自然阅读 A5/A6/A7 分场景报告 120 秒候选次数／分钟、完整停留时长、有效悬停时间、轨迹范围、页面操作和视频观看状态。C3 自然 20 秒条件与 A 组分开。候选表示规则达到 500 ms，不标为误触或意图。圈选报告实际提交次数、漏选／多选、中断、面积、闭合误差和圈选耗时。

图仅展示实测连续轨迹及其导数；汇总曲线不跨缺口插值。单个参与者各做一轮，存在先后练习效应；两轮日志姿势不同，两轮均右手，不能据此比较左右手。

用户确认第一轮是拇指、第二轮是食指，报告依此标记。分析目录 `analysis/trajectory_2026-09-15/hands_run2/` 含报告、五张图、逐试次／运动／阅读／配对指标与质量校验。浏览器场景预览最多 20 Hz，全部坐标保留，全部原始场景事件用于分析；预览状态不作为分析样本。

回放采用小 HTML 页面加载独立 `replay-data.json`，避免将大数据嵌入网页正文导致浏览器工具传输超限。运行回放需要本地 HTTP 服务；`report.md` 和 PNG 可直接打开。

运行脚本需要 Python、numpy、pandas 和 matplotlib。本工作空间绘图依赖位于 `.tmp/plot-libs`，用 `PYTHONPATH=.tmp/plot-libs` 指定。换环境时安装这些公开依赖再运行 `qa/analyze_two_runs.py`；原始 CSV 不变，分析结果可重建。

## 2026-09-15 用户覆核与意图探索
用户确认 B1 都理解为点击 B。保留原始成功／失败与原指令，只对菜单已出现、实际点击 B 且原失败仅 WRONG_MENU_ITEM 的六条记录增加动作完成覆核。其他错误不修改。派生统计与回放同时展示原判定和覆核，记录 annotations 文件及用户确认来源。

C3 比较主动 HOVER_SELECT 前与自然 CANDIDATE 前的首次 500 ms 对象停留：用日志 startTime 定位停留开始，只取开始至开始＋500 ms 的实测点，不用触发后样本。完整窗必须在同一连续悬停段、有至少 12 点及 450 ms 覆盖；缺失窗记录排除原因。500 ms 达标本身不能成为这组比较的预测特征。使用 XY 速度中位数、位置 RMS 散布两个低复杂度特征，经 log1p 后用训练轮均值／标准差标准化，以类别和场景加权的正则逻辑回归探索，固定概率 0.5 阈值，不在测试轮调参。分别拇指训练→食指测试、食指训练→拇指测试，展示混淆计数、平衡准确率、ROC AUC 和每场景结果；缺少任一类别的场景不计算单独 AUC。Z 只描述原始值，不用于主要模型。

该分析判断轨迹是否包含与指令相关的线索，无法确认自然候选的真实心理意图；主动成功窗选择也会产生偏差，失败尝试另外报告。场景对象大小、阅读阶段、菜单几何、练习和单人重复测量均限制泛化。B1/B2/B3 可作主动停留描述，B4 作为移动圈选单独报告。

## 行动阶段补图
由已校验 SHA256 的 replay-data.json 中全部保留坐标和语义事件生成，不使用被降频的场景预览统计。运动数据限定原试次时段，过滤／断线规则沿用既有方法。新增有符号 XY 速度变化率，导数支持来自同段相邻速度边，边时间差至少 1 ms；正负分别表示加速／减速，二维加速度幅值单独保留。图中原始曲线与 80 ms 段内中位趋势并列，趋势仅用于观察，原始导数与支持序号导出。
B3 六次／姿势的全部路径、目标选择顺序和有效停留均展示；以最终 HOVER_SELECT 日志的 startTime 为进入有效停留时刻。比较前 300 ms 的接近速度与接下来的 500 ms 停留速度，仅取同一连续段且分别覆盖至少 200／450 ms 的记录。按试次分面而不拼接不同时刻或补点。采样抖动会放大导数，正负频繁切换不能直接解释为反复纠正或肌肉震颤。

## 整体特征发现与验证层次
整体路径图与 `behavior_phase_curves.png` 使用相同代表试次并导出其 ID。阶段曲线同时显示原始导数与同段 80 ms 移动中位趋势，标出有效驻留、菜单、圈选事件；B1/B2 叠加相同几何 A1 示例，只描述动作形态，不能代替试次分布或当显著性检验。B3/B4 的阅读路径图是场景参照，不是同几何对照。验证清单独立命名 `behavior_validation.json`，不覆盖旧验收记录。
A1–A4 单独描述接触操作，A5–A7 描述自然阅读悬停；B1–B4 描述主动行为家族。目标呈现前的起点稳定不进入目标阶段特征。B1/B2 与 A1 优先相同距离、尺寸和方向；B3/B4 缺少相同几何多目标基线。分段减速、低速驻留、无接触、多次离散驻留、闭合大面积路径是候选家族特征，协议决定的完成结构不得称为已验证的心理意图特征。
从 A 自然阅读规则候选与 B1–B3 500 ms 实测窗只用两个 XY 特征训练类别／试次加权正则逻辑回归，固定正则0.1、阈值0.5，单次冻结后检验 C3。C 数据在此前已探索，此分析只构成回顾性留组检验，不是预注册或未查看测试集。C1/C2 若缺少完整正例就报告覆盖不足；触屏后才判别的输入来源不能支持触屏前预测。C3 场景对象面积和自然候选机会与抽象 B 有域差异，需要报告跨场景性能。
圈线候选独立扫描全 A/B/C 实测悬停窗，不读取闭合事件作识别依据，门槛沿用既有几何协议并明确窗口扫描近似。不把自然长段与短操作直接比较最大值；显示可观测悬停时间和机会数量。面积按窗口实测点加最长20pt算法闭合边的二维鞋带公式，非物理3D面积， self-crossing 的带符号面积可能相互抵消。

## Home position 候选与过滤
同一段A基线后60秒的候选抑制只用前60秒估计及训练主簇≥6的可用性，不以检查段复现结果挑选模型；它只评估自然候选减少量，不能报告意图分类准确率。C3同时记录从A前60秒估计结束至实际检查窗的墙钟间隔，展示同场景跨任务迁移的时效限制。
获取时间在2/5/10/15/20/30/45/60秒前缀分别计算，只纳入已经结束的完整实测窗口；至少6个主簇窗才称初步候选，相邻有新增窗口的估计中心差≤20pt称在线暂稳。前缀相对60秒中心的稳定与后60秒位置复现为回顾性验证，不能使用未来坐标改善早期中心。主模拟只用训练/后半段主簇各至少6窗、中心差≤50pt的模型；不足时不进行位置抑制。观察得到的是Pencil笔尖的手机局部XY热点，不能确认真实手指3D休息姿态；离开感应范围时的home不可观测。
从完成的 A5–A7 自然基线前 60 秒估计每姿势、每场景的自然低运动热点，后 60 秒检查复现。独立连续段内切非重叠500ms窗口，至少450ms与12点覆盖；窗口RMS≤15pt且速度中位≤100pt/s才参与home估计。候选位置不是固定实验起点，也不是已确认的心理休息状态。按窗口覆盖时间计权选最密集50pt圆簇并估计中心；全场景合并模型每场景同权，跨场景和前后半段中心差异单独报告。训练/后半段各至少6窗且中心相距≤50pt才记位置复现。30/80pt半径仅敏感性检查，不用C挑选最佳参数。
固定A估计中心，再对B1–B3、C3原有500ms窗口计算home内的实测覆盖时间占比；占比≥80%并且仍为低运动窗时模拟抑制静态选择。分别报告只用home规则与原A/B速度-RMS模型叠加后的误报、主动保留率及每姿势/场景结果。C已探索，仍属回顾性分析。圆选运动不能以home裁剪，目标位于home时允许主动操作；分析只探索负向先验，不改原日志或正式采集。
